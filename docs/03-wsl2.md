# 第 3 章：安装或核验 WSL 2

**建议学时：2 小时｜状态：本机核验已实测；全新安装仅官方资料核对**

## 学习目标

- 安装 WSL 2 和默认 Ubuntu，或核验既有环境；
- 理解 WSL 版本、发行版版本与 Linux 内核版本的区别；
- 掌握安全的更新、关闭和故障定位命令。

## 概念图

~~~text
wsl.exe（管理器） → WSL 2（运行模式） → Ubuntu（发行版） → uname（内核）
~~~

## 路线 A：电脑尚未安装 WSL

以管理员身份打开 **PowerShell**：

~~~powershell
wsl --install
~~~

按提示重启，再从开始菜单打开 Ubuntu。该命令通常启用所需组件、安装 WSL 与默认 Ubuntu，并将新发行版设为 WSL 2。若已经装过 WSL，命令可能显示帮助而不是重复安装，此时转路线 B。

需要指定发行版时：

~~~powershell
wsl --list --online
wsl --install -d Ubuntu
~~~

如果下载长期停在 0.0%，微软文档给出的候选方式是：

~~~powershell
wsl --install --web-download -d Ubuntu
~~~

先记录完整错误；不要同时叠加多套手工修复。

## 路线 B：本机已有 WSL

在 **PowerShell**：

~~~powershell
wsl --version
wsl --status
wsl --list --verbose
~~~

预期表格中 Ubuntu 的 VERSION 为 2。若为 1：

~~~powershell
wsl --set-version Ubuntu 2
~~~

转换可能耗时并需要足够磁盘空间，执行前备份重要 Linux 文件。Codex 0.115 起不支持 WSL 1，因此本教材不提供 WSL 1 主流程。

## 常用管理命令

~~~powershell
wsl -d Ubuntu
wsl --set-default Ubuntu
wsl --update
wsl --shutdown
~~~

- <code>wsl -d Ubuntu</code>：启动指定发行版。
- <code>wsl --update</code>：更新 WSL 本身，不等于更新 Ubuntu 软件包。
- <code>wsl --shutdown</code>：关闭所有发行版和 WSL 2 轻量虚拟机，会中断其中进程。

## 实验：三种版本

分别记录：

~~~powershell
wsl --version
wsl --list --verbose
wsl -d Ubuntu -- uname -r
~~~

解释：第一项是 WSL 应用版本；表格中的 2 是架构模式；<code>uname -r</code> 是 Linux 内核版本。Ubuntu 版本要在发行版内部用 <code>cat /etc/os-release</code> 查看。

## 故障分支

- 错误 <code>0x80370102</code>：通常需要检查虚拟化和 Virtual Machine Platform。
- 安装后未见 Ubuntu：运行 <code>wsl --list --verbose</code>，区分未安装与未启动。
- 代理/DNS 问题：先保存错误、确认 Windows 网络和时间，再查 WSL 故障文档。
- 忘记密码：不要注销发行版；第 4 章提供重置步骤。
