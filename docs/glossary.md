# 术语表

| 术语 | 新手解释 |
|---|---|
| Linux | 操作系统内核；日常所说“Linux 系统”通常还包含大量用户空间工具。 |
| 发行版 | 把 Linux 内核、工具、软件包和默认配置组合起来的系统，如 Ubuntu。 |
| WSL 2 | Windows 上运行 Linux 环境的技术，使用真实 Linux 内核。 |
| Ubuntu | 本教材在 WSL 2 中使用的 Linux 发行版。 |
| Terminal | 显示和输入命令的窗口，例如 Windows Terminal。 |
| Shell | 解释命令的程序，例如 PowerShell 或 Bash。 |
| root | Linux 的最高权限用户，不等于 Windows 管理员账号。 |
| sudo | 以提升权限执行单条命令的工具。 |
| APT | Ubuntu/Debian 的软件包管理工具。 |
| 进程 | 正在运行的程序实例。 |
| 端口 | 主机或容器上服务通信使用的编号入口。 |
| 镜像 | 创建容器的只读模板。 |
| 容器 | 从镜像创建的隔离运行实例。 |
| Registry | 存放和分发镜像的服务，如 Docker Hub。 |
| Dockerfile | 描述如何构建镜像的文本文件。 |
| Compose | 用 YAML 声明和管理一个或多个容器服务。 |
| 卷/挂载 | 让容器使用持久数据或主机文件的机制。 |
| Git | 记录文件版本和差异的工具。 |
| 仓库 | Git 管理的一组项目文件和历史。 |
| Codex | 能阅读项目、提出计划、修改文件和运行验证的编码智能体。 |
| 沙盒 | 限制智能体命令可访问范围的技术边界。 |
| 审批 | 智能体在执行超出既定权限的操作前请求用户同意。 |
| AGENTS.md | 给 Codex 的项目级长期协作规则。 |
